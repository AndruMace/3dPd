# Credits

This project is a 3D remake of **Pixel Dungeon** by Oleg Dolya (watabou), released under the
GNU General Public License v3.0. Game rules are ported from, and all sprites, tiles, UI art, fonts,
music and sound effects are taken from, the original sources:

- https://github.com/watabou/pixel-dungeon (game, assets)
- https://github.com/watabou/PD-classes (Noosa engine)

`npm run refs` clones them at pinned commits into `reference/`, and `npm run assets` imports the
assets into `public/assets/` and regenerates derived data in `src/content/generated/`.

This project is likewise licensed under the GPL-3.0 (see `LICENSE`).
